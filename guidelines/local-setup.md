# Before you start using this repo

## Agentic tooling - Claude

Follow claude-site-url instructions to download Claude CLI.

## IDE - Visual Studio Code CLI

Follow visual-studio-code instructions to download Visual Studio Code - Desktop App.

1. Enable the VS Code CLI: Cmd+Shift+P → "Shell Command: Install 'code' command in PATH".
2. Install the Oxlint extension (this repo lints with oxlint, not ESLint): `code --install-extension oxc.oxc-vscode`.
